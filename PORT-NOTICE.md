# Dramatic Shape 1.8.0 Generation II port

This source tree combines two bodies of work with different distribution
status:

1. Dramatic Shape 1.8.0, supplied by the user. Its README states that
   redistribution of post-1.6.0 code requires permission. No public-source
   license was included in the supplied 1.8.0 archive.
2. Generation II compatibility modifications by UNDERdecodedHD. Those
   modifications were distributed with the MIT license reproduced in
   `LICENSES/GEN2-PORT-MIT.txt`.

The MIT grant for the Generation II modifications does not grant permission
to redistribute Dramatic Shape 1.8.0 itself. Keep a repository containing this
complete combined tree private unless the Dramatic Shape copyright holder
provides permission. A public repository can instead contain original
documentation and a permission-safe installer design that requires each user
to supply their own lawfully obtained 1.8.0 archive, but that installer should
be reviewed before publication.
